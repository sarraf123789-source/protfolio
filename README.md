# 💎 Ruchi Sarraf | Personal Portfolio

Welcome to my personal portfolio website. This project showcases my journey as a Junior Software Developer (Web).

I have built and customized this platform using modern tools and frameworks, focusing on creating a clean, responsive, and user-friendly experience. I also explored dynamic content management and deployment practices during development.

## ✨ Key Features

- **Clean and minimalist UI** focused on usability.
- **Dynamic content structure** using JSON-based data.
- **Basic admin interface** for managing content.
- **Responsive design** for all devices.
- **Deployed using modern tools**.

## 🛠️ Technical Stack

- **Frontend**: [Next.js 15 (App Router)](https://nextjs.org), [React 19](https://react.dev)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) (Modern utility-first CSS)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (High-end transitions)
- **Icons**: [Lucide React](https://lucide.dev)
- **Backend**: [Next.js API Routes](https://nextjs.org/docs/app/building-your-application/routing/route-handlers)
- **Deployment**: [Vercel](https://vercel.com)

## 🚀 Getting Started

To run this project locally:

1.  **Clone the Repository**:
    ```bash
    git clone <your-repo-link>
    ```
2.  **Install Dependencies**:
    ```bash
    npm install
    ```
3.  **Run Development Server**:
    ```bash
    npm run dev
    ```
4.  **Access Local Site**: Open [http://localhost:3000](http://localhost:3000)

## 🔐 Admin Dashboard

Control every aspect of the site without touching the code.
- **URL**: `/admin`
- **Current Password**: `admin123` (Configurable in `src/app/admin/page.tsx`)

### Manageable Sections:
- **Identity**: Name, Title, Bio, Social Links, and Assets (Photo/Resume).
- **About**: Multiline biographies.
- **Skills**: Technical proficiency (categorized) and soft skills.
- **Experience**: Professional journey with roles and duration.
- **Education**: Academic background and status.
- **Certifications**: Professional certificates with award links.
- **Projects**: Portfolio showcase with tech tags and live links.
- **Contact & Footer**: Real-time updates for location and social identity.
